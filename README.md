# 2회고사 공부방

2회고사(2026년 12월 18·21·22일) 준비용 개인 공부 사이트. 공부자료를 모아 읽고, 객관식·단답형·서술형 문제를 풀고, 서술형은 Claude 가 채점한다.

- 사이트: https://naujin-dev.github.io/study-hub/
- 과목: 국어, 영어, 통합사회, 통합과학, 한국사, 과학탐구실험, 일본어 (수학은 공부 시간만)

## 기능

| 화면 | 하는 일 |
| --- | --- |
| 홈 | 시험까지 남은 날, 오늘 복습할 문제 수, 오답 수, 오늘 계획, 과목별 하루 목표, 과목별 진도와 정답률, 약한 단원 |
| 자료 | 과목별 단원 목록, 본문 읽기, 전체 검색, 다 읽음 표시, 인쇄, 자료 이름·순서 바꾸기, 자료 내용으로 Claude 에게 질문 |
| 문제 | 과목·단원·유형·조건(안 푼 것, 오답, 복습할 때 된 것, 헷갈림 표시)으로 골라 풀기. 연습(바로 채점)과 실전(시간 제한, 끝나고 한꺼번에 채점) |
| 채점 | 객관식 바로 채점. 단답형은 표기 차이를 무시하고 비교하고, 다르면 AI 가 뜻이 같은지 확인. 서술형은 AI 가 기준별 점수, 빠진 점, 고친 답안을 준다. API 키가 없으면 claude.ai 채팅에 복사·붙여넣기로 무료 채점 |
| 오답노트 | 틀리거나 부분 점수 받은 문제. 내 답, 정답, AI 피드백, 해설. 두 번 연속 맞히면 빠진다 |
| 복습 | 맞힌 문제는 1·2·4·7·14일 뒤에 다시 나온다 |
| 암기카드 | 뒤집어 보며 외우기. 모른 카드는 그 자리에서 다시 나온다 |
| AI 문제 만들기 | 자료 본문으로 새 문제를 만들어 이 기기에 저장 |
| 일정·계획 | 과목별 시험 날짜·범위, 날짜별 할 일 |
| 수학·공부 시간 재기 | 수학은 자료 없이 시간만 잰다. 과목별 스톱워치(재는 동안 머리띠에 표시), 빈 시간 채우기, 기록 취소 |
| 하루 목표 시간 | 홈에서 목표를 정하면 오늘 채운 비율과 어제 공부 시간을 보여 준다 |
| 공부 일지 | 날짜별로 쌓이는 공부 흔적: 자료 읽은 시간, 푼 문제 묶음과 결과, 카드, 실전, 질문, 형광펜, 끝낸 계획. 하루 한 줄 회고 |
| 풀이 이력 | 한 문제를 풀 때마다 쓴 답, 결과, AI 채점이 모두 남는다 |
| 형광펜·메모 | 자료 본문에 4색 형광펜과 메모, 단원 메모. 과목·색별 모아보기 |
| 이어 읽기 | 자료를 실제로 본 시간을 세고, 지난번 읽던 곳부터 연다 |
| 기록 | 공부한 날 달력, 누적 문제 수·공부 시간, 정답률 변화, 과목별 공부 시간, 단원별 정답률, 쌓은 기록(달성 목록), 집중 타이머 |
| 동기화 | GitHub 비공개 Gist 에 기록을 쌓아 여러 기기에서 합친다 |
| 백지 복습 | 자료를 덮고 기억나는 것을 다 쓴 뒤 핵심어를 몇 % 떠올렸는지 비교 (백지 공부법·파인만 기법) |
| 확신도 체크 | 채점 전 "확실/애매/찍음". 찍어서 맞힌 것은 복습에 다시 나온다 (메타인지) |
| 오답 원인 | 개념 부족·암기 부족·실수·문제 잘못 읽음·시간 부족으로 분류 |
| 섞어 풀기 | 과목을 번갈아 섞은 20문제 (인터리빙) |
| 시험 전 정리 | 과목별 메모·형광펜·오답·헷갈린 문제·모르는 카드를 한 장으로 |
| 영어 책 문제 먼저 | 영어 자료에 책 문제가 붙어 있으면 그 문제를 다 풀어야 정리가 열린다 |

| 설정 | 동기화, API 키, 모델, 자료 가져오기, 백업 |

## 처음 한 번 할 일

1. GitHub 저장소 **Settings → Pages** 에서 Source 를 "Deploy from a branch", 브랜치 `main`, 폴더 `/ (root)` 로 저장한다. 1~2분 뒤 사이트 주소가 열린다.
2. **Settings → Actions → General → Workflow permissions** 를 "Read and write permissions" 로 바꾼다. 자료를 올렸을 때 `data/index.json` 을 자동으로 다시 만드는 데 필요하다.
3. (선택, 유료) 사이트 [설정] 에 Anthropic API 키를 넣으면 버튼 하나로 AI 채점이 된다. 키 없이도 무료로 쓸 수 있다: 채점 화면의 "채점 요청 복사" 를 claude.ai(무료 계정 가능)나 공부 Claude 채팅에 붙여넣고, Claude 가 준 답을 사이트에 다시 붙여넣으면 점수와 피드백이 들어간다.

## 자료 넣기

공부자료를 만드는 Claude 에게 [PROMPT.md](PROMPT.md) 의 프롬프트를 보낸다.

- 채팅 Claude: 받은 JSON 을 사이트 [설정 → 자료 가져오기] 에 붙여넣는다. 그 기기에만 저장된다.
- Claude Code: `data/packs/<과목>/<id>.json` 으로 올리고 푸시한다. 모든 기기에서 보인다.

형식은 [docs/FORMAT.md](docs/FORMAT.md).

직접 확인하려면:

```bash
python3 scripts/check_packs.py   # 검사, data/index.json 다시 만들기
python3 -m http.server 8000      # http://localhost:8000
```

## Notion 주간 계획 (비공개)

공부 계획은 공개 저장소에 올리지 않는다. Notion "School / Exam / 주간 계획" 을 마크다운으로 옮겨 `data/private/` (git 이 무시함) 에 두고

```bash
python3 scripts/build_plan.py data/private/notion-plan.md data/private/study-hub-plan.json
```

로 만든 `study-hub-plan.json` 을 사이트 설정 → 자료 가져오기 → 파일 고르기 로 넣는다. 이 기기와 비공개 Gist 에만 저장되고, 동기화로 다른 기기에도 들어간다. 사이트에서 체크한 것은 Notion 으로 돌아가지 않는다.

Notion 계획을 고쳤으면 Claude Code 에게 "Notion 주간 계획 다시 가져와서 가져오기 파일 만들어 줘" 라고 하면 된다.

## 사이트 코드를 고쳤을 때

커밋 전에 `python3 scripts/bump_version.py` 를 돌린다. index.html 의 스크립트 주소에 새 버전 번호를 붙이고 version.json 을 바꾼다. 열려 있던 사이트는 다음에 화면을 켤 때 새 버전을 알아채고 새로 연다. 안 돌리면 태블릿 브라우저가 예전 파일을 계속 쓸 수 있다.

## 알아둘 것

- 오프라인 모드: `sw.js` 가 사이트 파일을 기기에 저장해 둔다. 인터넷이 있으면 늘 새 파일을 먼저 받고, 없을 때만 저장본을 쓴다. AI 채점·동기화·새 자료 받기는 인터넷이 필요하다.

- 기록은 그 기기의 브라우저에 쌓이고, [설정 → 기록 동기화] 에 GitHub 토큰(Gists 읽기·쓰기 권한만)을 넣으면 내 비공개 Gist 에도 쌓인다. 같은 토큰을 넣은 기기끼리 기록이 합쳐진다. 기록은 지우지 않고 더하기만 해서 두 기기에서 동시에 공부해도 사라지지 않는다.
- API 키와 GitHub 토큰은 Gist 와 백업 파일에 들어가지 않는다.
- 기록 구조: `js/store.js` 맨 위 설명. 푼 기록과 복습 일정은 쌓인 기록(events)에서 매번 다시 계산한다.
- AI 기능은 브라우저에서 Anthropic 으로 바로 요청한다. 쓴 만큼 API 요금이 나온다. 기본 모델은 Claude Opus 5.5 이고 설정에서 Sonnet 5.5, Haiku 5.5 로 바꿀 수 있다.
- 저장소가 공개라서 `data/packs/` 의 자료는 누구나 볼 수 있다. 남에게 보이면 안 되는 자료는 저장소에 올리지 말고 [자료 가져오기] 로만 넣는다.
